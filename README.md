# Thuraya
Thuraya is a smart tourism platform for tourism in Saudi Arabia  
aims to support Saudi Vision 2030 by making travel services modern and easy to use. Thuraya 
acts as a bridge between travelers and tourism businesses. Through Thuraya, users can explore 
different tourist destinations and learn about various tourist experiences within the Kingdom. Users 
can also book tourist packages and complete the online payment process securely. Thuraya 
revenue model is based on a commission-based system, when a user books a service through our 
platform, we receive a percentage of the payment from the service provider for every successful 
booking.
